# 🎮 Tic Tac Toe - Player vs AI & Friend

A modern and interactive Tic Tac Toe game built with React.js and Material UI.

Players can choose between:
- 🤖 Play against AI
- 👥 Play with a Friend

## 🚀 Features

- 🎮 Play Tic Tac Toe with a friend
- 🤖 Play against AI
- ✨ Modern and responsive UI
- 🎨 Attractive game interface
- ⚡ Built with React.js
- 🧩 React Router navigation
- 🎨 Material UI components
- 📱 Responsive design

## 🛠️ Technologies Used

- React.js
- JavaScript
- Material UI
- React Router DOM v5
- HTML5
- CSS3
